
# Museum Management System

This project implements a museum management system using Object-Oriented Programming (OOP) in Python.

The system models art displays, museum subscribers, and their interactions within a museum.

## Overview

The project simulates museum operations, including managing art displays, tracking subscriber entries, and analyzing the popularity of different artworks.

## Features

- Create and manage art displays
- Represent paintings and statues using object-oriented programming
- Manage museum subscribers
- Track subscribers' remaining entries
- Load museum data from a text file
- Identify the most popular art displays among subscribers

## Technologies

- Python
- Object-Oriented Programming (OOP)
- File Handling

## Main Classes

- **ArtDisplay** – Represents an art display in the museum
- **MuseumSubscriber** – Represents a museum subscriber and tracks their remaining entries
- **Museum** – Manages art displays and subscribers

## How to Run

1. Make sure Python is installed.

2. Create a text file named `museum.txt` using the required input format.

3. Place the following files in the same folder:
   - `museum_management.py`
   - `museum.txt`

4. Run the program:

   ```bash
   python museum_management.py
   ```

## Example Output

The program can display:

- A list of art displays in the museum
- Updates to subscribers' remaining entries
- The most popular art displays based on subscriber activity
